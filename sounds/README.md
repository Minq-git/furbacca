# Sounds

- **sounds/ts/** — TypeScript audio bridge (non-blocking aplay).
- **sounds/assets/** — WAV files for touch-triggered playback (ALSA/aplay to I2S DAC).

Place WAV files in **sounds/assets/**.

- **giggle.wav** — played on head touch (BCM 17). Use a WAV file (e.g. 44.1 kHz, 16-bit) for low-latency playback.
